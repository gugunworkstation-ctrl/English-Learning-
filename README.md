# English Kids 5

Aplikasi Android sederhana untuk belajar 5 kosakata bahasa Inggris per hari.

## Fitur
- 5 kata baru per hari
- Text-to-Speech bahasa Inggris
- Review kata hari sebelumnya
- Kuis arti kata
- Tandai Sulit Dihafal / Sulit Diucapkan
- Daftar latihan khusus
- Kata yang salah otomatis masuk latihan
- Progress tersimpan offline
- Dashboard orang tua
- Build APK otomatis dengan GitHub Actions

## Build tanpa laptop
Upload seluruh isi project ini ke repository GitHub. Workflow `.github/workflows/build-apk.yml`
akan membangun APK. Hasilnya bernama `EnglishKids5-v1.0.apk` di artifact `EnglishKids5-APK`.
